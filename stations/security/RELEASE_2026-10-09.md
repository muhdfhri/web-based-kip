# Production v1 - 9 Oktober 2026

Folder kerja: MEWAH-KIP-NEW. Branch: production-v1.

Rilis ini memindahkan perbaikan CCTV Feed ke folder baru: streaming grid melalui
satu koneksi, substream untuk preview, antrean frame dibatasi, reconnect, status
kamera berdasarkan frame, dan CRUD PostgreSQL sesuai struktur dump server.
Detail perubahan dan hasil pengujian ada di CCTV_MIGRATION.md.

## Sebelum update PC server Ubuntu

1. Backup database mewah_main, mewah_security, mewah_security_ai dan file .env
   server yang sedang dipakai. Git tidak menyimpan database atau .env.
2. Ambil branch production-v1 di checkout server. Jangan menyalin .env laptop;
   gunakan kredensial PostgreSQL server. Pastikan main-service/backend/.env
   tersedia agar Station View dapat membaca mewah_main.station_registry.
3. Pasang dependency sesuai lockfile. Frontend memerlukan npm ci --legacy-peer-deps
   karena konflik dependency 3D yang sudah ada. Pasang requirements Python CCTV
   pada lingkungan Python server; PM2 dapat memakai SECURITY_AI_PYTHON untuk
   memilih executable Python dari virtual environment.
4. Jalankan SQL berikut pada mewah_security setelah backup. Ini bukan restore
   database dan tidak mengganti link kamera atau data AI:

   psql -U postgres -d mewah_security -v ON_ERROR_STOP=1 -f stations/security/database/cctv_compatibility.sql

5. Build frontend dari main-service/frontend dengan npm run build jika server
   menggunakan hasil build. Pastikan proses PM2 menjalankan checkout baru dan
   environment Python yang benar, lalu restart layanan yang diperbarui: main-service,
   frontend-shell (jika menggunakan Vite), security-station, security-ai-service.
   Hindari menjalankan dua salinan layanan pada port yang sama.
6. Periksa Station View, daftar kamera, dan tampilan seluruh kanal. Sumber utama
   RTSP: mewah_security.public.cctv_cameras.rtsp_url. Dump yang diberikan berisi
   lima entri dengan URL kanal yang sama; push kode tidak memindahkan 16 URL
   kamera dari database laptop. Gunakan konfigurasi kanal server yang sebenarnya.

SQL kompatibilitas sudah diuji pada database sementara. Database operasional
PC server belum diperbarui dari laptop ini. Jangan restore dump lama ke atas
DB server yang sudah berisi data operasional baru.
